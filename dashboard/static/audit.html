CRITICAL .keyfile committed to public repo
A .keyfile is visible in the public repo root. This may contain API keys or secrets. Rotate exposed credentials, remove the file from git history, and add it to .gitignore.
git filter-branch --force --index-filter "git rm --cached --ignore-unmatch .keyfile" --prune-empty --tag-name-filter cat -- --all git push origin --force --all echo ".keyfile" >> .gitignore
CRITICAL Log files committed - run_output.txt, error_log.txt, test_output.txt
Runtime log and output files are tracked by git. These can leak runtime details and should be ignored by source control.
echo "run_output.txt" >> .gitignore echo "error_log.txt" >> .gitignore echo "test_output.txt" >> .gitignore git rm --cached run_output.txt error_log.txt test_output.txt
